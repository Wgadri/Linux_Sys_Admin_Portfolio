# Linux Basics - Working with Directories and File Navigation

## Objective

This lab focuses on understanding the core Linux commands used to move through directories and inspect the filesystem structure.

## Environment

- Operating System: Ubuntu Linux
- Version Control: Git and GitHub

## Commands Practiced

| Command | Description                                     |
|---------|-------------------------------------------------|
| pwd     | Displays the current working directory          |
| cd      | Changes the current directory                   |
| ls      | Lists files and directories                     |
| ls -a   | Displays hidden files and directories           |
| ls -l   | Shows detailed file and directory information   |
| ls -lh  | Displays file sizes in a readable format        |
| mkdir   | Creates a new directory                         |
| mkdir -p| Creates parent directories if they do not exist |
| rmdir   | Removes an empty directory                      |
| tree    | Displays the directory structure                |

### Tasks Completed

### 1. Checking the Current Location

The `pwd` command was used to confirm the current working directory.

### 2. Listing Files and Directories

The following commands were used to inspect files and folders:
- `ls`
- `ls -l`
- `ls -a`
- `ls -lh`

These commands helped display directory contents, file details, hidden files, and file sizes in a more readable format.

### 3. Exploring the Root Directory

I navigated to `/` and reviewed the main system directories used in Linux.
- `/home` - User home directories
- `/etc` - System configuration files
- `/var` - Variable data such as logs

### 4. Absolute and Relative Paths

A path that begins with `/` starts from the root of the filesystem.
A path that does not begin with `/` is relative to the current working directory.
