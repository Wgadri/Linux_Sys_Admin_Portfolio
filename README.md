# System Administration Linux

Welcome to my **Linux System Administration Portfolio**. This repository captures my hands-on learning journey in Linux system administration through practical exercises and documentation.

## Objective
The goal of this project is to strengthen my practical Linux system administration skills through guided lab work. Each exercise focuses on real command usage and includes supporting screenshots for reference.
